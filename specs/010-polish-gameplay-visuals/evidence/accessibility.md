# Accessibility Evidence

- Housie “View all” opens by touch/keyboard, closes with Escape, and returns focus to the trigger.
- Hub host actions are 45 px at settled 390×844 and 640×360 layouts.
- Ludo reduced motion uses a 200 ms result fade/scale with no travel, shadow, blur, or shake.
- Confetti is decorative, pointer-transparent, and removed in reduced-motion mode.
- Housie chips remain complete at 320, 390, 640, and 844 widths.
- Hub, Ludo, Housie, and UNO responsive passes reported zero horizontal overflow.
- Source diagnostics report no TypeScript or build errors.
